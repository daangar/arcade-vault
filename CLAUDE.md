# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Arcade Vault: an online games platform where players compete for the highest score. The project is early-stage (still the Create Next App scaffold: `app/page.tsx`, default metadata). The README says it follows a spec-driven workflow (`/spec` and `/spec-impl`) using skills from `Klerith/fernando-skills` (installed with `npx skills@latest add Klerith/fernando-skills`).

## Next.js version warning

This uses Next.js 16.4.6 with React 19.3 and has breaking changes from older Next.js. Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) and heed deprecation notices. `AGENTS.md` is regenerated by `next dev`; commit it rather than removing it.

## Architecture notes

- App Router only (`app/`). `layout.tsx` uses the globally typed `LayoutProps<"/">` helper rather than hand-written props types.
- `next.config.ts` enables `cacheComponents` and `partialPrefetching` (plus `experimental.agentFeedback`). Cache Components changes how dynamic/cached data access works, so check the docs before fetching data or reading request APIs in components.
- Tailwind CSS v4 is wired through Turbopack: a `*.css` rule in `next.config.ts` runs `@tailwindcss/turbopack`, and `app/globals.css` uses `@import "tailwindcss"` with an `@theme inline` block mapping CSS variables (light/dark via `prefers-color-scheme`) to theme colors and Geist fonts. There is no `tailwind.config` file.
- TypeScript is strict. The import alias `@/*` maps to the repo root (not `src/`).
